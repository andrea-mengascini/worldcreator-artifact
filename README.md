# Metaverse Attack Videos – Paper Submission Materials
This folder contains the supplementary materials for our paper submission. The main file, `index.html`, presents a collection of videos demonstrating the world creator attacks in metaverse environments. Each attack is shown from two perspectives:

- **Victim** (or Bystander): The viewpoint of the user being targeted within the metaverse.
- **Attacker**: The viewpoint of the adversary attempting to compromise the system.

For each attack, explanatory text is provided to clarify what is happening in the videos.

## How to Use

1. Open `index.html` in your web browser.
2. Select a platform at the top to view the corresponding attack scenarios.
3. For each attack, you can play/pause the videos and read the explanations provided.

## Important Note for Brave Browser Users

**Audio playback in the videos may not work in Brave browser** due to its restrictions regarding local file origins. For best results, use another browser (such as Chrome), or serve the files via a local web server.
